## 🧠 Problem Statement

Given product catalog descriptions (text), predict the price of products. The challenge involves:
- **Noisy text data** with marketing fluff, HTML tags, and inconsistent formatting
- **Product variants** (same product, different sizes/quantities) with different prices
- **Wide price range** requiring robust regression
- **Text-only approach** (no images or external features)

---

## 🚀 Solution Approach

### 1. **Data Preprocessing** (`prepare_training_data.py`)
- **Product-aware splitting**: Groups product variants together to prevent train/val leakage
- **Text cleaning modes**:
  - `title_only` (recommended): Keeps product title + Value/Unit info
  - `best`: Aggressive cleaning, removes marketing fluff
  - `smart`: Keeps lines with quantity/size information
  - `minimal`: Light cleaning only
- **Parallel processing** with multi-threading for fast I/O

### 2. **Model Architecture** (`train_model.py`)
```
Input Text → BERT Tokenizer → BERT Encoder → Pooling → Dropout → Linear Head → Price
```
- **Pretrained BERT** (`bert-base-uncased`) for text understanding
- **Regression head** with dropout for regularization
- **Mixed precision training** (FP16) for GPU efficiency
- **Linear warmup scheduler** for stable training

### 3. **Inference Pipeline** (`predict.py`)
- Batch processing with configurable batch size
- Automatic device detection (CPU/GPU)
- Optional prediction clipping for realistic price ranges

## 🎮 Usage

### Step 1: Prepare Training Data

Convert raw CSV to preprocessed training/validation splits:

```bash
python prepare_training_data.py \
    --csv train.csv \
    --out-dir training \
    --split 0.95 \
    --seed 42 \
    --workers 16 \
    --clean title_only
```

**Arguments:**
- `--csv`: Path to input CSV with columns `sample_id,catalog_content,price`
- `--out-dir`: Output directory for preprocessed data (default: `training`)
- `--split`: Train fraction 0-1 (default: 0.95)
- `--seed`: Random seed for reproducibility
- `--workers`: Number of parallel threads
- `--clean`: Cleaning mode (`title_only`, `best`, `smart`, `minimal`)

### Step 2: Train Model

Train BERT regression model on preprocessed data:

```bash
python train_model.py \
    --root training \
    --model_name bert-base-uncased \
    --epochs 3 \
    --batch_size 16 \
    --lr 2e-5 \
    --max_len 128
```

**Arguments:**
- `--root`: Path to preprocessed data directory
- `--model_name`: HuggingFace model name (default: `bert-base-uncased`)
- `--epochs`: Number of training epochs
- `--batch_size`: Batch size for training
- `--lr`: Learning rate (default: 2e-5)
- `--max_len`: Maximum sequence length (default: 128)

**Outputs:**
- `best_model.pt`: Best model checkpoint (based on validation SMAPE)
- `train_manifest.csv`: Training data manifest
- `val_manifest.csv`: Validation data manifest
- `val_predictions.csv`: Validation set predictions

### Step 3: Run Inference

Predict prices on test data:

```bash
python predict.py \
    --input_csv test.csv \
    --model_path best_model.pt \
    --output_csv predictions.csv \
    --batch_size 64 \
    --clip_min 0.05
```

**Arguments:**
- `--input_csv`: Test CSV with columns `sample_id,catalog_content`
- `--model_path`: Path to trained model checkpoint
- `--output_csv`: Output file for predictions
- `--batch_size`: Batch size for inference
- `--clip_min`: Optional minimum price threshold

**Output CSV format:**
```
id,predicted_price
12345,29.99
67890,15.49
...
```

## 🧩 Technical Details

### Data Cleaning Pipeline
1. **Multiline CSV reading** with proper quote handling
2. **Product hashing** to group variants (MD5 of normalized title)
3. **Text normalization**:
   - Unicode fraction conversion
   - HTML entity decoding
   - Whitespace normalization
   - Duplicate punctuation removal
4. **Parallel processing** with ThreadPoolExecutor

### Model Training
- **Optimizer**: AdamW with weight decay (0.01)
- **Scheduler**: Linear warmup (10%) + linear decay
- **Loss function**: L1 Loss (Mean Absolute Error)
- **Regularization**: Dropout (0.1)
- **Early stopping**: Based on validation SMAPE

### Inference Optimizations
- Batch processing for throughput
- Non-blocking GPU transfers
- Automatic mixed precision (AMP)
- Progress tracking with tqdm
